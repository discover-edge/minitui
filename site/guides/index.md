# Guides

- [Getting started](getting-started.md) — Install MiniTui, run the demos, and write a first app.
- [Async data and HTTP](async.md) — Load data without blocking the UI: results come back on the UI thread.
- [Screens and components](screens.md) — Structure a larger app as a stack of screens built from components, with focus, overlays and scoped key bindings.
- [Layout](layout.md) — Divide the screen with constraints, and split it into resizable panes.
- [Widgets](widgets.md) — The built-in widgets, each a builder that draws into a `CellBuffer`.
- [Theming](theming.md) — Colors come from a `Theme`: pick one, change a few slots, or follow the terminal's light or dark background.
- [Keys and widget state](keys-and-state.md) — Key bindings, and the state objects behind interactive widgets: lists, text fields, trees, selection and the clipboard.
- [Drawing on the CellBuffer](drawing.md) — Draw directly: cells, strings, colors and styled text.
- [The terminal](terminal.md) — What MiniTui does with the terminal: queries, keyboard protocols, the mouse, running other programs, debugging and backends.
- [Testing](testing.md) — Test screens, components and whole apps without a terminal.
- [The app and helpers](app-and-helpers.md) — The `App` builder's options, and small helpers for geometry, commands and status messages.
- [Extending](extending.md) — Write your own widgets and drawing primitives.
